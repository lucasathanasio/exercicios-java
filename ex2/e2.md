# 🟡 Exercício 2 — Aluno

Crie uma classe `Aluno`.

## Atributos

- `matricula` — `int`
- `nome` — `String`
- `idade` — `int`
- `nota` — `double`

## Requisitos

1. Todos os atributos devem ser `private`.
2. Crie um construtor recebendo todos os atributos.
3. A `matricula` deve ser maior que `0`.
4. O `nome` não pode ser `null` nem vazio.
5. A `idade` deve estar entre `16` e `100`.
6. A `nota` deve estar entre `0` e `10`.
7. Valores inválidos devem gerar `new Exception`.
8. Crie getters para todos os atributos.
9. Crie setters para todos os atributos.
10. Os setters também devem validar os valores.

## Item extra

Implemente `Comparable<Aluno>` fazendo com que os alunos sejam comparados pela **nota**.

> Neste exercício, você deve avaliar como implementar o `compareTo()`.
