# 🟢 Exercício 1 — Produto

Crie uma classe `Produto` para representar um produto de uma loja.

## Atributos

A classe deve possuir os seguintes atributos:

- `codigo` — `int`
- `nome` — `String`
- `preco` — `double`
- `quantidade` — `int`

## Requisitos

1. Todos os atributos devem ser `private`.
2. Crie um construtor que receba todos os atributos.
3. O `codigo` não pode ser menor ou igual a `0`.
4. O `nome` não pode ser `null` nem vazio.
5. O `preco` não pode ser menor que `0`.
6. A `quantidade` não pode ser menor que `0`.
7. Caso algum valor seja inválido, lance uma `new Exception`.
8. Crie getters para todos os atributos.
9. Crie setters para todos os atributos.
10. Os setters devem realizar as mesmas validações do construtor.

## Observação

Não crie `compareTo()`, `clone()` ou outros métodos.
