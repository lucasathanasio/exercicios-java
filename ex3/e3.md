# 🟠 Exercício 3 — Conta Bancária

Crie uma classe `ContaBancaria`.

## Atributos

- `numero` — `int`
- `titular` — `String`
- `saldo` — `double`

## Requisitos

1. Todos os atributos devem ser `private`.
2. Crie um construtor com os três atributos.
3. O número deve ser maior que `0`.
4. O titular não pode ser `null` ou vazio.
5. O saldo inicial não pode ser negativo.
6. Valores inválidos devem lançar `new Exception`.
7. Crie getters para todos os atributos.
8. Crie setter apenas para o atributo `titular`.
9. Não crie setter para `saldo`.
10. O saldo só pode ser alterado por meio dos métodos solicitados abaixo.

## Métodos

Crie:

```java
depositar(double valor)
```

e:

```java
sacar(double valor)
```

### Regras

- O valor deve ser maior que `0`.
- Não é permitido sacar um valor maior que o saldo disponível.
- Valores inválidos devem gerar uma exceção.

## Atenção

Não crie um método `setSaldo()`.
