# 🔴 Exercício 4 — Funcionário

Crie uma classe `Funcionario`.

## Atributos

- `id` — `int`
- `nome` — `String`
- `salario` — `double`
- `cargo` — `String`

## Requisitos

1. Todos os atributos devem ser `private`.
2. Crie um construtor recebendo todos os atributos.
3. O `id` deve ser maior que `0`.
4. O `nome` não pode ser vazio ou `null`.
5. O `salario` deve ser maior que `0`.
6. O `cargo` não pode ser vazio ou `null`.
7. Utilize `new Exception` para valores inválidos.
8. Crie getters para todos os atributos.
9. Crie setters para todos os atributos.
10. Os setters devem validar os dados.

## Item extra

Implemente `Comparable<Funcionario>` para ordenar funcionários pelo **salário**.

Não implemente `clone()`.
